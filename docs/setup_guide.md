# Guide de Configuration

## 1. Prérequis

- Vagrant installé
- Puppet
- KVM/QEMU installé
- VirtManager installé

## 2. Étapes de Configuration

1. Cloner le dépôt Git.
2. Installer les dépendances requises (Vagrant, Puppet, etc.).
3. Configurer les clés secrètes dans GitHub (pour Gmail).
4. Exécuter `vagrant up` pour créer les VMs.
5. Exécuter les scripts de provisionnement.
6. Vérifier les tests de fonctionnalité et de sécurité.
